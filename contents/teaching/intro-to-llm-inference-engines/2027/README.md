# LLM 推理系统（2027）

本目录发布 2027 年首次开课使用的课程材料。正式课程共 8 讲，每讲 2 小时、48 页，总计 384 页；另有一份 60 页中文单文件速览，用于两小时导论或课程预习。英文两小时速览单独放在相邻的 `llm-inference-systems-english` 目录。当前版本按初学者的认知顺序补充基础概念、逐步算例、完整流程、易错点和课堂检查，并穿插 2024–2026 年推理系统研究案例。

1. 课程导论与评价指标
2. 请求生命周期与 Prefill / Decode
3. 请求调度与连续批处理
4. KV 缓存与状态管理
5. 推理系统架构与代码阅读
6. 执行优化与异构平台适配
7. 论文比较与实验验证
8. 开源实践与课程项目

`slides/lectures` 中的 8 个 PPTX 文件与教学文件夹中的正式课件逐字节一致。`slides/quick-intro` 存放中文单文件两小时快速介绍版。公开页面不再混入误标为 2026 年的旧版 PDF、tutorial 或实验单。
